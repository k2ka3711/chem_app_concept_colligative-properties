# chem_app_concept_colligative-properties
高等学校化学「希薄溶液の性質」概念理解学習アプリ

分子の世界（ミクロの界面現象・束一的性質）と巨視的な物理量（蒸気圧降下、沸点上昇、凝固点降下、浸透圧）をつなぎ、溶質粒子の存在が溶媒の動的平衡に与える影響を直感的に学べる静的Webアプリケーションです。

---

# 特徴と学習構成

- **完全な単一静的Webアプリ**: 外部ライブラリ・CDN・サーバー不要で、index.html 1ファイルのみでオフライン動作
- **STEP 0: はじめに（共通視点）**: 4つの現象（蒸気圧降下・沸点上昇・凝固点降下・浸透圧）を一覧し、すべて「溶質粒子の存在による溶媒粒子の平衡・移動の変化」という共通視点であることを概観
- **STEP 1: 蒸気圧降下・沸点上昇**: 純水とグルコース水溶液の気液界面を並列比較。液面を溶質粒子が占有することによる蒸発速度の低下、飽和蒸気圧降下（ラウールの法則 $P = x_{\text{水}} P^\circ$）、沸点上昇（$\Delta T_b = K_b m$）を可視化
- **STEP 2: 凝固点降下**: 純水と水溶液の固液界面（結晶格子）を並列比較。溶質粒子による結晶化妨害（凝固速度低下）、温度低下による融解速度低下と新たな動的平衡（$\Delta T_f = K_f m$）の成立メカニズムを可視化
- **STEP 3: 浸透圧**: U字管（中央不透過隔壁・底部小型半透膜）モデル。純水から水溶液への水分子の優先的通過、液面差（$\Delta h$）による静水圧（押し戻す力）と浸透平衡（ファントホッフの式 $\Pi = cRT$）を可視化
- **微視的な変化速度メーター（相対値 %）**: 「蒸発 vs 凝縮」「凝固 vs 融解」「正浸透 vs 逆圧押し戻し」の速度バーと動的平衡バッジ（気液平衡・新平衡・浸透平衡など）をリアルタイム表示
- **ワンクリック設定ボタン**: 各平衡状態（沸点・凝固点・浸透平衡）へワンタップで遷移できるプリセットボタンを搭載
- **数式モデルとの架け橋**: 各STEPで対応する物理化学公式（ラウールの法則、沸点上昇度、凝固点降下度、ファントホッフの式）とリアルタイム計算結果を併記
- **発展（束一的性質）**: 3つのSTEPを体験後に、粒子の種類によらず粒子数（質量モル濃度・モル濃度）にのみ依存する「束一的性質（colligative properties）」のまとめを表示

# 更新履歴

## [ver.1.0.0] — 2026-08-27 JST

### 新規公開（初版）
- 高等学校化学「希薄溶液の性質」の概念理解を目的としたWebアプリの初版をリリース
- HTML / CSS / JavaScript のみによる単一の index.html 構成で完全オフライン動作に対応

### 分子シミュレーション（ミクロ）
- 純水とグルコース水溶液の界面現象を並列比較する Canvas アニメーション描画
- 気液平衡における液面蒸発・凝縮の分子挙動および沸騰現象の可視化
- 固液平衡における氷結晶格子への吸着・脱離と溶質粒子による凝固阻害の可視化
- U字管における底部小型半透膜と中央不透過隔壁による半透膜通過・液面上昇（$\Delta h$）の可視化

### 変化速度メーターと動的平衡
- 各現象における正逆方向の微視的変化速度（相対値 %）をバーグラフでリアルタイム比較
- 凝固点降下において、凝固点温度（$T = -\Delta T_f$）で凝固速度と融解速度が厳密に一致する新平衡の成立を数値・バッジで可視化
- 浸透圧において、液面差に伴う押し戻し圧力が正浸透と釣り合う浸透平衡を可視化

### 操作性・UI設計
- スマートフォン・タブレット・PCに対応したレスポンシブデザイン
- グルコース濃度倍率ボタン（$\times 1/4 \sim \times 4$）と温度スライダーによる双方向インタラクション
- 純水基準温度（100.00 ℃、0.00 ℃）および溶液の平衡温度（沸点・凝固点）へのワンクリック設定ボタン
- 現象の因果関係をわかりやすく解説する「今、何が起きている？」動的解説ボックス
