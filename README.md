# 希薄溶液の性質

高校化学「希薄溶液の性質」の初学者向け Web 教材です。分子モデルを動かしながら、蒸気圧降下・沸点上昇・凝固点降下・浸透圧のしくみを、ステップごとに確かめます。

`index.html` 1 ファイルで動きます（ダブルクリックで開く／校内サーバーや GitHub Pages に置く）。インターネットにつながらない環境では、日本語フォントがパソコンの標準フォントに替わりますが、動作は変わりません。

公開ページ：https://k2ka3711.github.io/chem_app_concept_colligative-properties/

## 使い方（生徒向け）

1. 図の横（スマホでは図の下）にある **「やること」** を見る。
2. 青くかこまれた **「いまここ」** の指示を、上から順にやる。ボタンやスライダーは「やること」の中にだけあります。
3. 全部に ✓ がつくと「まとめ」が出る。読んだら下のバーの **「次へ」** を押す。

各ステップは「予想 → 操作して観察 → 理由を選ぶ → 濃さを変えて確かめる → まとめ（式）」の順です。スマホでは図が画面の上に止まり、「やること」を操作しながら図の変化を見られます。

## ステップ

| | 問い | 操作と分子モデル |
| --- | --- | --- |
| 0 | はじめに | 使い方と 4 つの現象 |
| 1 | グルコースをとかすと、水蒸気の量は変わる？（蒸気圧降下） | ふたをした容器 A（純水）・B に、グルコースを入れる。蒸発・凝縮の回数と水蒸気の分子の数（グラフ）。B の水蒸気が減って、新しい気液平衡で落ちつく |
| 2 | 水溶液は、何 °C で沸とうする？（沸点上昇） | A・B を加熱。蒸気圧のバーが大気圧の線に届くと沸とう。蒸気圧曲線のグラフ。1.0 mol/kg → 100.52 °C、2.0 mol/kg → 101.04 °C |
| 3 | 水溶液は、何 °C でこおる？（凝固点降下） | 氷と液体の境目の拡大図。0 °C では B の 融解 ＞ 凝固 で氷がとける。温度を下げて 凝固 ＝ 融解 になる温度（−1.85 °C、2.0 mol/kg で −3.70 °C）をさがす |
| 4 | 半透膜をはさむと、水はどちらへ動く？（浸透圧） | U 字管と半透膜の拡大図。A → B の移動で液面差ができて止まる。B を押して液面をそろえる圧力 ＝ 浸透圧（*Π* = *cRT*、濃さ 2 倍で 2 倍） |
| 5 | まとめと確認 | 4 つの現象の表（分子で見ると／結果／式）、電解質（NaCl）の粒子の数、確認問題 5 問 |

## モデルについて

- 画面の分子は見やすくするため数を少なくし、溶質の粒子を実際の割合より多くかいています。液体の粒子のうち水分子の割合を *x* = 1 − 0.18 *m* とし、4 つの現象をすべてこの *x* で動かしています（「溶質が水分子の割合を下げる」という共通の見方）。
- STEP 1：液面の水分子だけが蒸発し、気体の分子は液面に当たると一定の割合で凝縮します。蒸発の速さは *x* に比例するので、B の水蒸気の数 ÷ A の数 ≒ *x*（ラウールの法則）がシミュレーションから出てきます。
- STEP 2：蒸気圧はアントワン式。水溶液の蒸気圧曲線は、沸点上昇度 *K*<sub>b</sub>*m* だけ右にずらしています。沸とう中は濃さが変わらないとしています。
- STEP 3：凝固の速さ ∝ *x*、融解の速さ ＝ 1 ＋ (0.18/*K*<sub>f</sub>) *t* とし、凝固 ＝ 融解 になる温度がちょうど −*K*<sub>f</sub>*m* になるようにしています。
- STEP 4：A → B の速さ 1、B → A の速さ ＝ *x* ＋（液面差・押す圧力による押しもどし）。液面差は実際よりずっと小さくかいています（実際の 1.0 mol/L の浸透圧は約 25 × 10<sup>5</sup> Pa）。
- 定数：*K*<sub>b</sub> = 0.52 K·kg/mol、*K*<sub>f</sub> = 1.85 K·kg/mol、*R* = 8.31 × 10<sup>3</sup> Pa·L/(K·mol)、浸透圧の温度 27 °C（300 K）。

## 開発

```sh
node tools/build.mjs          # src/ から index.html を作る
node tools/check-model.js     # モデルが教科書どおりの傾向を示すか確かめる
```

- `src/app.html`：画面・操作・「やること」のしくみ
- `src/model.js`：計算と分子モデル（画面とテストの両方で使う）
- `tools/check-model.js`：回帰テスト（ラウールの法則の比、沸点・凝固点で速さがつり合うこと、浸透圧で液面がそろうことなど 17 項目）

- ステップを分けました：蒸気圧降下と沸点上昇を別のステップに、最後に「まとめと確認」（表・電解質・確認問題 5 問）を追加。
- モデルを見直しました（科学的な正確さ）。
  - 蒸気圧降下：蒸発・凝縮を分子のできごととして数え、水蒸気の数の変化をグラフに表示。以前の「速さのバー」は固定の式の値で、蒸気圧の下がり方と合っていませんでした。
  - 沸点上昇：温度スライダー（純水が 100 °C をこえても液体のままになる）をやめ、加熱すると沸点で温度が止まる形にしました。蒸気圧曲線のグラフと、蒸気圧と大気圧のバーを追加。
  - 凝固点降下：温度を変えると境目が一瞬で動く表示（「温度で氷の量が決まる」という誤解のもと）をやめ、氷の量が時間とともに増える・減る・変わらない形にしました。
  - 浸透圧：液面差による押しもどしの分をバーで分けて表示し、「液面をそろえるのに必要な圧力 ＝ 浸透圧」を操作で確かめる課題を追加。
- 表記を教科書に合わせました：*K*<sub>b</sub> = 0.52、*K*<sub>f</sub> = 1.85 K·kg/mol、Δ*t* = *K*<sub>b</sub>*m*、*Π* = *cRT*（*R* = 8.31 × 10<sup>3</sup> Pa·L/(K·mol)）。化学式は Arial、数値・単位は Times New Roman、物理量は斜体（TeX Gyre Schola）。
