# 希薄溶液の性質

高校化学「希薄溶液の性質」の Web 教材です。蒸気圧降下・沸点上昇・凝固点降下・浸透圧を、**「水溶液から出る水分子・入る水分子のつり合い」という1つの見方**でつなげて学びます。

`index.html` 1 ファイルで動きます（ダブルクリックで開く／校内サーバーや GitHub Pages に置く）。インターネットにつながらない環境では、日本語フォントがパソコンの標準フォントに替わりますが、動作は変わりません。

公開ページ：https://k2ka3711.github.io/chem_app_concept_colligative-properties/
（現象を1つずつ確かめる以前の版：https://k2ka3711.github.io/chem_app_concept_colligative-properties/classic.html ）

## 1つの見方

> 溶質の粒子は境目をこえられない。だから、水溶液から「出る」水分子だけが減る。
> つり合い（出る ＝ 入る）を取りもどす方法が、4つの現象になる。

| 場面 | 水溶液の相手 | 出る／入る | つり合いを取りもどす方法 | 現象 |
| --- | --- | --- | --- | --- |
| 1 | 水蒸気 | 蒸発／凝縮 | 水蒸気が減って「入る」も減る | 蒸気圧降下 |
| 2 | 泡（大気圧の水蒸気） | 蒸発／凝縮 | 温度を上げて「出る」を増やす | 沸点上昇（100.52 °C） |
| 3 | 氷 | 凝固／融解 | 温度を下げて「入る」を減らす | 凝固点降下（−1.85 °C） |
| 4 | 純水（半透膜ごし） | 水溶液→純水／純水→水溶液 | 圧力をかけて「出る」を増やす | 浸透圧（24.9 × 10<sup>5</sup> Pa） |
| 5 | つなげる | — | 溶質の種類と量を変え、4つの値が同じ倍率で動くことを見る | *Δt* = *Km*、*Π* = *cRT*、電解質 |

## 使い方（生徒向け）

1. 図は境目の拡大図。下のバーで、水溶液から **出る** 水分子と **入る** 水分子の数（純水のつり合い ＝ 100）をくらべる。
2. **「やること」** の「いまここ」を、上から順に進める（予想 → グルコースを溶かす → つり合いを取りもどす）。
3. 全部に ✓ がつくと「まとめ」が出る。下のバーの **「次へ」** で次の場面へ。

アプリの操作は 20〜25 分ほどです（場面 1〜4 が各 4 分前後、場面 5 が 5 分前後）。

## モデルについて

- 純水のつり合いを 1 とし、溶質粒子の濃さ *m* のとき「出る」を *x* = 1 − 0.18 *m* 倍にします。見やすくするため、実際（1.0 mol/kg で約 1.8 % 減）より大きく下げています。表示される沸点・凝固点・浸透圧は実際の値です。
- 場面 1：入る ＝ 水蒸気の数 ÷ 純水のときの数。水蒸気が *x* 倍に減ってつり合います（ラウールの法則）。
- 場面 2：出る ＝ *x* ＋ (0.18/*K*<sub>b</sub>)(*t* − 100)、入る ＝ 1（泡の中は大気圧の水蒸気）。加熱すると 100 ＋ *K*<sub>b</sub>*m* °C で沸騰し、温度が止まります。
- 場面 3：出る ＝ *x*、入る ＝ 1 ＋ (0.18/*K*<sub>f</sub>) *t*。−*K*<sub>f</sub>*m* °C でつり合います。
- 場面 4：出る ＝ *x* ＋ 0.18 ×（液面差 ＋ 押す圧力）、入る ＝ 1。浸透圧と同じ圧力で押すと、液面がそろってつり合います。液面差は実際よりずっと小さくかいています。
- 「境目の粒子のうち水分子の割合が減るので、出ていく水分子が減る」は、高校の教科書と同じ粒子モデルによる説明です。厳密には、溶質が混ざることで水溶液中の水が安定になる（エントロピーが増える）ことが原因で、溶質が境目を物理的にふさぐわけではありません。
- 場面 5：蒸気圧は 25 °C（純水 3.17 kPa）、浸透圧は 27 °C。うすい水溶液として mol/kg と mol/L を同じ値とみなし、NaCl は完全に電離するとしています。
- 定数：*K*<sub>b</sub> = 0.52 K·kg/mol、*K*<sub>f</sub> = 1.85 K·kg/mol、*R* = 8.31 × 10<sup>3</sup> Pa·L/(K·mol)。

## 開発

```sh
node tools/build.mjs          # src/ から index.html を作る
node tools/check-model.js     # モデルが教科書どおりの傾向を示すか確かめる
```

- `src/app.html`：画面・操作・「やること」のしくみ（4場面は 1 つの設定の表 `SC` から作る）
- `src/model.js`：計算とモデル（画面とテストの両方で使う）
- `tools/check-model.js`：回帰テスト（どの場面も溶質で「出る」だけが 0.82 倍になること、100.52 °C・−1.85 °C・浸透圧でつり合うことなど 20 項目）
- `classic.html`：ver.2.0.0 の完成ファイル（ソースは Git の履歴にあります）

### [ver.3.0.0] — 2026-11-10
- 4つの現象を**1つの見方**で学べるように作り直しました（1人1台・1時間の授業で、初めて学ぶ生徒が使う想定）。
  - 見方：水溶液と「相手」（水蒸気・泡・氷・純水）の**境目**で、水溶液から**出る**水分子と**入る**水分子の数をくらべる。溶質の粒子は境目をこえられないので、溶質が入ると「出る」だけが減る。つり合いを取りもどす方法のちがいが、4つの現象になる。
  - 4つの場面を、同じ拡大図・同じ「出る／入る」のバー・同じ流れ（予想 → 溶かす → 取りもどす → まとめ）にそろえました。場面 2 以降は「同じ見方で予想しよう」と問いかけます。
  - 最後の場面「つなげる」を追加：溶質（グルコース・尿素・NaCl）と量を変えると、4つの値が同じ倍率で動きます。確認問題 4 問と、自分のことばでまとめる欄つき。
  - 沸点上昇は、沸騰している水に溶質を入れると泡がつぶれる（沸騰が止まる）ところから始め、泡の表面での蒸発・凝縮として表しました。
  - 浸透圧より大きい圧力で押すと水が逆向きに動く（逆浸透）ことも試せます。
- モデルを1つの形にまとめました（`rates`・`step`）。回帰テストは 20 項目。
- これまでの版（現象を1つずつ、濃さも変えて確かめる）は `classic.html` に残しています。

- ステップを分けました：蒸気圧降下と沸点上昇を別のステップに、最後に「まとめと確認」（表・電解質・確認問題 5 問）を追加。
- モデルを見直しました（科学的な正確さ）。
  - 蒸気圧降下：蒸発・凝縮を分子のできごととして数え、水蒸気の数の変化をグラフに表示。以前の「速さのバー」は固定の式の値で、蒸気圧の下がり方と合っていませんでした。
  - 沸点上昇：温度スライダー（純水が 100 °C をこえても液体のままになる）をやめ、加熱すると沸点で温度が止まる形にしました。蒸気圧曲線のグラフと、蒸気圧と大気圧のバーを追加。

  - 浸透圧：液面差による押しもどしの分をバーで分けて表示し、「液面をそろえるのに必要な圧力 ＝ 浸透圧」を操作で確かめる課題を追加。
- 表記を教科書に合わせました：*K*<sub>b</sub> = 0.52、*K*<sub>f</sub> = 1.85 K·kg/mol、Δ*t* = *K*<sub>b</sub>*m*、*Π* = *cRT*（*R* = 8.31 × 10<sup>3</sup> Pa·L/(K·mol)）。化学式は Arial、数値・単位は Times New Roman、物理量は斜体（TeX Gyre Schola）。
